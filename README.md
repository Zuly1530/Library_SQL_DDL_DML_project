# Library_SQL_DDL_DML_project

SQL-проект базы данных библиотеки, созданный для практики работы с MySQL.

## О проекте

Проект представляет собой базу данных библиотеки, содержащую информацию об авторах, книгах и жанрах.

В проекте реализованы:
- создание базы данных;
- создание таблиц и связей между ними;
- добавление данных;
- SQL-запросы для получения и анализа информации;
- использование подзапросов;
- оконные функции;
- CTE;
- сортировка и группировка данных;
- работа с агрегатными функциями.

## Структура проекта

- `DDL.sql` — создание базы данных, таблиц, индексов и внешних ключей.
- `DML.sql` — добавление и изменение данных.
- `Queries.sql` — SQL-запросы для выборки и анализа данных.

## Используемые технологии

- MySQL
- DBeaver
- SQL
- Git
- GitHub

## Цель проекта

Проект создан для практического изучения SQL и работы с реляционными базами данных, а также для демонстрации навыков работы с SQL в портфолио.

# Library_SQL_DDL_DML_project

SQL project of a library database created to practice working with MySQL.

## About the Project

The project represents a library database containing information about authors, books, and genres.

The project includes:

* database creation;
* table creation and relationships between tables;
* data insertion;
* SQL queries for retrieving and analyzing information;
* subqueries;
* window functions;
* CTEs;
* data sorting and grouping;
* aggregate functions.

## Project Structure

* `DDL.sql` — database, tables, indexes, and foreign keys creation.
* `DML.sql` — data insertion and modification.
* `Queries.sql` — SQL queries for data retrieval and analysis.

## Technologies Used

* MySQL
* DBeaver
* SQL
* Git
* GitHub

## Project Goal

The project was created to practice SQL and relational database skills and to demonstrate SQL knowledge as part of a portfolio.
